# What is Blackout?
"Blackout" is a 2D stealth and puzzle-action game built in Unity. The core gameplay loop centers around "hacking" or cracking puzzles to disable security mechanics, and utilizing movement tools in order to infiltrate a corporation called ARGUS. This project and idea was fully developed and created by me using Unity, with some Art Assets being used from the Unity Asset Store. All Music, SFX, Code, and Core Mechanics were created by me. Music and SFX were created using FL Studio. ARGUS is a corrupted  corporation that conducted experiments on innocent civilians with the intention to "Save the World." The main character's parents were a part of those tests, and ever since he lost them, he's been training to break in and steal ARGUS' data chip, which holds records, video footage, patient reports, and test results of the whole thing. That is his main goal, to bring justice and take down any other corporations similar to ARGUS.

You can Download and play this game by downloading the Blackout.zip file, extracting, and running the Blackout Application (the one with the Unity symbol next to it). I would love to hear feedback as this is my first game I have made solo! Thank You!
